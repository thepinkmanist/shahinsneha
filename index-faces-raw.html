Build RAW face search index

Same tool as the main gallery's face index, pointed at the RAW photo categories instead. Run this once (from this page, in a normal browser tab — not automation) to let visitors search "find someone in the photos" inside the RAW section. Everything happens on this device; nothing is uploaded anywhere. This is full-resolution RAW photos across four categories (1455 + 957 + 909 + 287 = 3608 photos), so it will take considerably longer than the main gallery's index did — likely a few hours. Leave the tab open and focused the whole time.

Every photo is checked with both detectors and the results are merged, so a group shot where one detector misses a face still gets caught by the other — this is what fixes photos coming up with no face found. Progress is also saved to this browser as it goes, so if the tab crashes, the laptop sleeps, or you accidentally close it, reopening this page will offer to pick back up instead of starting a category over.
