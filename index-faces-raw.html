Build RAW face search index

Same tool as the main gallery's face index, pointed at the RAW photo categories instead. Run this once (from this page, in a normal browser tab — not automation) to let visitors search "find someone in the photos" inside the RAW section. Everything happens on this device; nothing is uploaded anywhere. This is full-resolution RAW photos across four categories (1455 + 957 + 909 + 287 = 3608 photos), so it will take considerably longer than the main gallery's index did — likely a few hours. Leave the tab open and focused the whole time; if the tab goes to sleep or the laptop locks, the browser will throttle or pause it. When each category finishes, its file downloads automatically — drop all four into the data/ folder in this project and push.
